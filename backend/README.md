# TeethTech CRM MVP — Go backend

Автономный Go 1.26 HTTP-сервис. Java/Maven и Redis для запуска не требуются. Основной способ запуска всего продукта описан в [README продукта](../README.md).

## Устройство

- `cmd/server` — запуск, миграции, bootstrap, фоновые задания и корректная остановка.
- `internal/bootstrap/migrations` — встроенные SQL-миграции PostgreSQL с проверкой SHA-256 и блокировкой конкурентного запуска. Старый Java-MVP принимается после сверки Flyway CRC32; история Flyway сохраняется.
- `internal/identity` — JWT, BCrypt, ротация refresh-сессий, блокировка входа и права.
- `internal/orders`, `workflow`, `catalog`, `clinic` — полный цикл заказов и настройки лаборатории.
- `internal/kpi` — отчёт по снимкам завершений, даты UTC+5, итог по всему периоду и страницы событий.
- `internal/files` — приватные вложения в MinIO/S3, потоковое скачивание и сохраняемая multipart-загрузка.
- `internal/notes`, `notifications`, `jobs` — личные заметки, внутренние уведомления и SLA.
- `internal/httpapi` — REST `/api/v1`, общие проверки прав и аудит.

Складские операции и начисления при работе с заказами отключены. Бухгалтерские API в MVP не предоставляются. Флаги склада и финансов должны быть `false`: их включение пока требует отдельной разработки. Пакеты отделены по доменам для последующего расширения.

## Проверка

```sh
go test -race ./...
go vet ./...
```

Полный автономный интеграционный сценарий после запуска Compose:

```sh
cd ..
python3 scripts/test-backend.py
```

Тест использует только БД `teethtech_mvp_go_test`, отдельный тестовый bucket и настоящий PostgreSQL/MinIO. Не запускайте его без понимания, что он пересоздаёт именно эту тестовую базу. Рабочая БД `teethtech_mvp` не меняется.

При запуске вне Docker укажите `DATABASE_URL`, `JWT_SECRET` (Base64, ≥32 декодированных байт), `MVP_ADMIN_PASSWORD`, `MVP_TRAINING_PASSWORD`, `AWS_S3_ENDPOINT`, `AWS_S3_ACCESS_KEY`, `AWS_S3_SECRET_KEY`, `AWS_S3_BUCKET_NAME`; затем `go run ./cmd/server`. По умолчанию HTTP слушает `127.0.0.1:8082`; Compose задаёт `:8081`. Для свежей базы административный пароль должен содержать 12–72 байта. Пустой учебный пароль отключает вход в учебные аккаунты случайным неизвестным паролем.

Readiness `/api/v1/actuator/health/readiness` проверяет PostgreSQL и bucket хранилища; liveness показывает работающий HTTP-процесс. Не публикуйте внутренний backend отдельно от frontend-прокси.


Новые установки инициализируются через `AccountsForMVP`: удаляются только фиксированные seed-заказы, рабочие статусы и маршруты; старые справочные виды работ выключены. Маркер bootstrap сохраняет последующие пользовательские изменения при перезапуске. Ранее установленная Java-база автоматически не очищается. Готовый BCrypt принимается из `MVP_ADMIN_PASSWORD_HASH`; повторное хеширование не выполняется. Управление активностью этапа: `PATCH /api/v1/order-statuses/{id}/activation` с JSON `{"active": false}` (ADMIN).
